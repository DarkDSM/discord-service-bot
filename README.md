# 🤖 Discord Service Bot

Un bot Discord pour gérer les prises de service avec tableau en direct, timers et statistiques.

## ✨ Fonctionnalités

- ✅ Tableau de service en temps réel (mise à jour chaque seconde)
- ✅ Boutons interactifs pour prise/fin de service
- ✅ Cumul automatique par jour
- ✅ Réinitialisation quotidienne à minuit
- ✅ Historique des 7 derniers jours
- ✅ Classement hebdomadaire
- ✅ Commandes de statistiques
- ✅ Interface intuitive avec embeds Discord

## 🚀 Installation

### 1. Prérequis
- Python 3.8 ou supérieur
- Compte Discord Developer
